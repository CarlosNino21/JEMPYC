# JEMPYC - Servicios Industriales

Sitio web profesional desarrollado para **JEMPYC Montacargas**, una empresa especializada en soluciones integrales para equipos industriales.

## Descripción del Proyecto
Este proyecto es una plataforma web corporativa diseñada para presentar los servicios de mantenimiento, reparación y renta de montacargas. El sitio tiene como objetivo principal convertir visitantes en clientes mediante una interfaz limpia, informativa y orientada a la acción.

### Características Principales
- **Diseño Responsivo:** Adaptado completamente a dispositivos móviles, tablets y escritorios.
- **Sección de Servicios:** Presentación clara y detallada de los servicios (Mantenimiento preventivo, correctivo, reconstrucción y renta).
- **Enfoque en Conversión:** Botones directos de contacto y acceso rápido a WhatsApp para cotizaciones.
- **Experiencia de Usuario:** Navegación fluida y carga rápida de elementos.

## Tecnologías Utilizadas
- **HTML5:** Estructura semántica del sitio.
- **CSS3:** Estilos personalizados, layouts modernos (Grid/Flexbox) y diseño responsivo.
- **JavaScript:** Funcionalidad para el menú móvil y efectos de navegación.
- **FontAwesome:** Iconografía profesional.
- **Google Fonts:** Tipografía *Montserrat* para una lectura elegante y moderna.
